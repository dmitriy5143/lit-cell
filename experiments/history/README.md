# Historical Architecture Search

The repository's original root `scripts/run_lachance_*` files reproduce an
earlier candidate-energy defense snapshot. They are retained for provenance but
are not the final publication model.

Later rejected branches and their exact dependencies are stored in
`experiments/publication/` because several final runners import shared utilities
from them. Scientific outcomes are summarized in
`evidence/architecture_search_ledger.csv`; the main manuscript discusses classes
of failure rather than presenting internal version numbers.
