# Project Identity

The canonical method and software name is **LIT-Cell: Local Innovation
Transport for Cell Motion**.

Use the following identifiers consistently:

- method in prose and figures: `LIT-Cell`;
- Python distribution: `lit-cell-forecasting`;
- Python package: `lit_cell_forecasting`;
- reproduction entry point: `scripts/reproduce_lit_cell.py`.
- canonical repository: `https://github.com/dmitriy5143/lit-cell`.

The name describes the reportable mechanism: a causal innovation state filter
followed by bounded local transport of completed neighbouring innovations. It
does not imply that the inferred effective functional is a measured physical
energy.

Historical experiment suffixes such as `v97`, `v157h`, and `v193` remain in
filenames because they identify frozen provenance. They are not model names and
should not appear in scientific claims.
